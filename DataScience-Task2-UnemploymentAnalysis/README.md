# Data Science Task 2: Unemployment Analysis with Python

## Project Overview
This project analyzes unemployment trends across Indian states using Python. It explores how unemployment rates fluctuated over time, compares regional differences, and highlights the economic impact of the COVID-19 lockdown.

## Key Insights
- **Temporal Trend:** Visualized national unemployment rate spikes during peak lockdown periods.
- **Regional Impact:** Ranked states with the highest and lowest average unemployment rates.
- **Pre vs. Post COVID Comparison:** Analyzed changes in Unemployment Rate and Labour Participation Rate across different years using statistical plots.

## Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## How to Run
1. Clone this repository to your local machine.
2. Place `Unemployment in India.csv` in the project directory.
3. Open `Unemployment_Analysis.ipynb` using Jupyter Notebook and execute all cells.
